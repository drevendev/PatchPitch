Five-post engineering story

Saved real local Gemma output, manually edited and accepted by the project author. Historical facts; no claim of a release today.

Post 1 of 5

Writing an update starts with choosing what actually shipped. PatchPitch uses local Gemma to turn those selected facts into an editable draft.

Post 2 of 5

One bug exposed that boundary: a delayed example load could replace the input while a draft was being generated. The screen could show facts from a different request.

Post 3 of 5

The fix reserves example loading through preparation. In the UI, loading and generation cannot overlap; a failed load keeps the previous input and draft.

Post 4 of 5

Regression tests cover delayed success and failure. They check the UI contract, not the quality of Gemma's writing. That still needs a real run and a careful read.

Post 5 of 5

Inspect the original notes, edit the wording, then copy or export the draft. Source links help with review; they do not make a sentence true.

Sources checked after editing
  • F01: Source — Crafting Batch feature, opened through Batch Board inside Workshop. Crafting Batch access requires Workshop level 10: at most 3 ordered job entries. Workshop level 50 expands the Batch to at most 5 entries. Each entry requests 1-99 completed crafting cycles, not an output-item count. Duplicate job entries allowed. Execute the ordered list once, then stop. Missing ingredients block that entry until supplied; later entries cannot skip ahead. Workers can supply materials; the Batch does not collect them.
  • F08: Source — Existing state kept when updating: shop, workforce, purchases, progress and random sequences. Pre-existing browser-save precaution: export a backup from Settings before changing devices or clearing browser data.

Run locally

Install Python 3.12, Ollama and the requirements from the release source. Install the selected model separately; adequate local memory is required.

python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
ollama pull gemma4:12b
.\.venv\Scripts\python.exe -m uvicorn patchpitch.app:app --host 127.0.0.1 --port 8000

Open http://127.0.0.1:8000. The model runs locally; this static page does not connect to a visitor's localhost.
