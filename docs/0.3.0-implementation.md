# 0.3.0 development implementation

Implementation record for 22 October 2026. The working version is `0.3.0.dev0`; a public release has not been created. Existing uncommitted Quillgrain/Telegram work was retained and extended.

## Implemented

- Installable CLI and `python -m patchpitch`, independent of the HTTP server/browser. Strict JSON/TOML jobs, machine-readable summaries/exit codes, plan, run, resume, validation and session export.
- Atomic run/attempt checkpoints, immutable original responses, recovery between response and export, preservation of edited files, per-run and cross-process inference locks. `--out-root` supports repeatable scheduled invocations with input-derived directories.
- Both reviewed facts and committed Git ranges. Git candidates remain labelled machine selected; selected saved pools bind source and candidate digests and can be reused without another extraction.
- X planning and deterministic selection of six observed tags per card, length reservation before writing, saved decisions, both original planning/writing responses, and shared validation of current text in CLI/studio. Explicit legacy support keeps old workflows readable and runnable.
- Optional Quillgrain 0.1.0rc3: direct local-pack compilation and bundle import, explicit registers, channel/language checks and exact generation snapshots. The compiler is an external installed dependency.
- DEV article/GitHub notes, editable publication files and campaign sessions that reopen in the studio. Explicit DEV draft adapter with receipts, ownership checks, protected published articles and uncertain-write reconciliation.
- [Runnable examples and operating instructions](headless.md), including Task Scheduler and a self-hosted Actions template. The example does not install/download a model or start a web server.

Reading the DEV article found an invented, invalid TOML example, an unsupported `20% gain` inside that example, and an escaped paragraph separator. The existing numerical warning identified the percentage, but acceptance was not semantic approval. Original responses were retained. The implementation now rejects unsourced code/CLI examples, unsupported percentage claims and escaped prose separators, and the sample input supplies the actual runnable command as a source snippet. These guards have dedicated negative tests; they do not prove general factual accuracy.

The first live Quillgrain article was rejected after 45.257 s for escaped paragraph separators. A separate experiment adding a string regex to the model grammar timed out at the configured 420 s; no response was available. That experiment was removed. Those attempts remain in their original run directories; no automatic repair or retry was introduced.

The final article contract uses structured sections and individual paragraphs. PatchPitch joins the model's paragraphs with Markdown headings, and inserts selected source code blocks verbatim by cited source ID. It does not rewrite model prose or ask the model to retype a command. The original structured response remains available separately from the assembled article.
