## Stabilization follow-up, 2026-10-21 (owner review pending)

Generation records now retain the original API response and input snapshot for
all five formats and single-card rewrites. Rejections include the available raw
response, reason, model identity, elapsed time and request hash. Timeouts without
a response preserve that absence. The optional record viewer uses literal text;
Copy/Download JSON is explicit. Records stay in tab memory only, are not sent to
telemetry, and do not provide session restoration. Accepted original responses
remain separate from editable review snapshots. No automatic retry or text repair
was introduced.

The full local suite passed 205 tests (15 dependency deprecation warnings). This
includes rejection/transport failure across all formats, safe raw-response display,
preserved edits and Markdown export, immutable failed JSON after a successful
retry, single-card failure preservation, and offline telemetry privacy checks.
These tests use MOCK inference and do not establish live writing quality.

A separate real Crafting Batch run used the normal `scripts/start_local.ps1`
application at port 8000 and local Ollama `gemma4:12b`. No capture middleware,
auxiliary response server or replay was used. The original brief produced a
rejected response in about 31 seconds: it included `[C01]` in prose and incorrectly
said the list stops after the first completed job. The UI retained that response.
An explicit retry changed only the voice brief to request plain paragraphs without
headings, source IDs or inline hashtags; it passed in 11.752 seconds. The rejected
record remained byte-identical after retry and manual editing. Both records were
exported through the application's Copy record JSON action. The prepared edited
final has 662/1600 characters; owner acceptance of this new run is pending.

This stabilizes inspection and recovery. It does not fix model hallucinations,
prove semantic validation, explain the earlier long latency, or resolve the
deferred X composer check. Private run records and screenshots remain under
ignored `artifacts/stabilization-0.2.0/`. Release, Pages, X and DEV publication
remain unperformed. This follow-up is prepared locally for review, without a
GitHub push or merge.
